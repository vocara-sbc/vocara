# 09-管理后台菜单设计

> Vocara 管理后台（business/web/admin，Vue3 + TS + Naive UI）的信息架构设计。
> 菜单配置在 `src/layouts/default/menu.ts`，按权限码过滤渲染；
> 角色与权限码映射在 `pkg/middleware/rbac/rbac.go`。

## 二、呼入接待页内结构

呼入接待维护接入号到队列/技能组的路由。欢迎音、等待音、工作时间、非工作时间处理
（挂断 / 留言 / 转座席 / 转队列及提示音）在页内"高级设置"折叠面板中维护，不单独占用菜单。

## 三、各角色可见菜单

| 角色 | 可见菜单 |
|---|---|
| admin | 全部菜单 |
| supervisor（班长） | 仪表盘、通话记录（呼入/呼出）、工单管理、客户管理、系统监控、统计报表（座席/队列/趋势分析）、系统管理（座席/技能组/队列/呼入接待/组织机构/表单模板/表单管理） |
| agent（座席） | 座席工作台、通话记录、工单管理、客户管理 |

座席登录后的默认首页为座席工作台，不设仪表盘。个人中心与修改密码在右上角用户下拉中提供，
不占用菜单。

## 四、设计约定

1. **FreeSWITCH 实例不纳入管理界面**：节点配置（sip_profile/directory/dialplan/xml_curl 等）
   以配置文件维护，不提供在线维护页面，`tb_fs_instance` 仅作配置登记。
2. **呼入接待与线路管理分设**：线路管理维护中继物理通道，呼入接待维护号码路由，
   DID 与队列/技能组的关联只在呼入接待中配置。
3. **工单管理、客户管理不设权限码**：所有登录角色均可见。
4. 需权限控制的菜单项声明权限码 `menu:<module>:<action>`，不声明的菜单项登录即可见；
   父级菜单的权限码决定整组是否可见，子菜单按各自权限码过滤，子菜单全部不可见时父级不渲染。
5. **菜单分组与路由分组相互独立**：菜单按业务信息架构分组（`menu.ts`），
   路由按资源路径分组（`router/index.ts`，如座席、组织机构、技能组、分机同属 `/agent/*`），
   二者通过路由 key 关联。
